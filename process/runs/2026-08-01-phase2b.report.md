Working tree after turn 1: empty. It analysed the project, read the `dom-css` notes, laid out
six questions and stopped — on the model that had failed this three times running.

The sentence now reads *„Der Kunde liest mit und antwortet. Beende deinen Zug, wenn du etwas von
ihm brauchst"* — it says a human is reachable and how to reach them, and nothing about when to
speak. „Abschlussnachricht" had been read as *questions come at the end*, i.e. after the work.

**This is the third attribution of the same observation, and the first correct one.** Run `alt-a`
called it a playbook gap. `sonnet-base` corrected that to model disposition. It was neither: the
harness was instructing the opposite of §4, and Opus obeyed the harness while Sonnet obeyed the
playbook. Two models never disagreed about §4 — they disagreed about my sentence.

Worth keeping in view: every step of that chain looked like solid evidence at the time. What
broke it open each time was a control that varied one thing — a second model, then a reworded
prompt.

## Asking first is cheaper, by a lot

| Run | Model | Turns | Cost | |
|---|---|---|---|---|
| `alt-a` | Opus | 33 | $1.88 | |
| `phase1` | Opus | 33 | $2.56 | +36 % — §5 prose, stack fetch |
| `sonnet-base` | Sonnet | 48 | $1.57 | |
| `phase2` | Opus | 52 | $4.04 | built with defaults, then confirmed |
| **`phase2b`** | Opus | 32 | **$1.84** | **−54 %** — asked, then built once |

The cost curve reversed, and not because anything got smaller. The playbook is *larger* than in
any earlier run — §5 technique prose, F1/F2/F6/F7, plus the roster table. `phase2` spent $3.20
building an implementation before knowing what was wanted, then $0.84 confirming it happened to
be right. `phase2b` spent $0.44 asking and $1.40 building once.

**Ask-before-build is not only better practice, it is the single largest cost saving measured so
far** — larger than anything Phase 4 tooling is likely to produce. That reframes the Phase 4
target: the baseline to beat is $1.84, not $4.04.

## Honest disclosure by the hire, worth recording

It reported that Alt+**Shift**+A also triggers, because it guards only against Ctrl and Cmd so a
held Shift doesn't kill the easter egg. Nobody asked; it is a deliberate trade-off, stated rather
than hidden. Not scored — no criterion covers it — but exactly the behaviour §4's assumption rule
is trying to produce.

## Harness fix made during this run

`verify-run.mjs` threw `ReferenceError: Cannot access 'URL' before initialization`. The roster
work added `new URL(...)` at module top to locate `catalog.json`, while the file already had a
local `const URL` for the page address — the local binding shadows the global from the top of the
module, so the catalog read failed before its own declaration ran. Renamed to `PAGE_URL`, with a
comment saying why, since the next person to add a global-`URL` call would hit it again.
